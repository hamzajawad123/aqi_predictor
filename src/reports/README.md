# Reports

- `final_report.md` (or `.pdf`) — full write-up: problem framing, EDA
  insights, feature engineering rationale, model comparison table
  (Persistence / Ridge / RandomForest / XGBoost / LSTM — RMSE/MAE/R²),
  SHAP findings, and architecture overview.

  auto-generated by the training pipeline; committed here so the report
